# 危害分析与 FMEA（ISO 14971）

> 对应 `docs/医疗器材合规优化方向.md` **第五章「风险管理文件」**、**第三梯队第 14 项**。
>
> **适用工程**：`vital_monitor_qml`。表格中的文件路径与验证用例均指本工程，
> 与 Widgets 版（`vital_monitor`）的同名文档**不可互换**。
>
> 本表用 FMEA 形式（失效模式 → 影响 → 现行控制 → 残余风险）覆盖本项目
> **已经识别并处置**的危害，以及**明确接受**的残余危害。
>
> **免责声明**：这是工程层面的危害分析演示，不是 ISO 14971 要求的正式风险管理文档
> （缺风险管理计划、风险可接受准则、生产后信息收集等要素）。

---

## 1. 严重度 / 可能性 / 检出度定义

| 等级 | 严重度 S | 可能性 P | 检出度 D（越低越好检出） |
|------|---------|---------|----------------------|
| 5 | 死亡 | 频繁 | 无法检出 |
| 4 | 严重伤害 | 很可能 | 仅事后可发现 |
| 3 | 中度伤害 | 偶尔 | 需专门检查 |
| 2 | 轻微伤害 | 很少 | 自检可发现 |
| 1 | 无伤害 | 极不可能 | 必然发现 |

**RPN = S × P × D**，本项目把 **RPN ≥ 40** 视为必须控制。

## 2. 危害分析表

### H-1 报警只报一次（**已修复**）

| 项 | 内容 |
|----|------|
| 失效模式 | 告警条件持续成立，但只在首次越限时报一次，此后静默 |
| 原因 | 原实现 `highLatched` 锁存，仅在数值回落时解锁 |
| 影响 | 医护以为「已经在报」，实际患者持续恶化无人知晓 → **死亡** |
| S / P / D | 5 / 4 / 4 → **RPN 80** |
| 控制措施 | 状态机 + 周期重复提示：`AlarmDetector::updateCondition()` 按 `alarmRepeatMs` 重报；确认后仍会再报；超时未确认自动升级 |
| 验证 | `alarm_state_test` 用例 1、2、3 |
| 残余风险 | 重复间隔过长（默认 5 s）在极端情况下仍可能延迟发现 |
| 残余 RPN | 5 / 1 / 2 = **10（可接受）** |

### H-2 传感器脱落 / 信号质量差被当作正常值（**已修复**）

| 项 | 内容 |
|----|------|
| 失效模式 | 导联脱落时输出「看起来正常」的数值，不报警 |
| 原因 | 旧实现无信号质量（SQI）概念 |
| 影响 | 低氧 / 停搏被显示为正常 → **死亡** |
| S / P / D | 5 / 4 / 5 → **RPN 100** |
| 控制措施 | `ChannelSample::quality` + `invalid`；`AlarmDetector` 对低 SQI / invalid **抑制生理报警并改发技术报警**；曲线与数值卡片以灰色 / `--` 呈现 |
| 验证 | `alarm_state_test` 用例 6 |
| 残余风险 | SQI 由模拟器生成，真实设备需传感器侧提供 |
| 残余 RPN | 5 / 2 / 2 = **20（可接受）** |

### H-3 运动伪迹被当作真实异常（**已修复**）

| 项 | 内容 |
|----|------|
| 失效模式 | HR 单帧从 60 跳到 250，被当作真实心动过速报警 |
| 原因 | 无变化率校验 |
| 影响 | 报警疲劳 → 医护关闭报警 / 忽略真报警 → **严重伤害** |
| S / P / D | 4 / 4 / 3 → **RPN 48** |
| 控制措施 | `ChannelSample::artifact`；伪迹样本不参与生理判定，改发技术报警「数据不可信」，伪迹消失后自动清除 |
| 验证 | `alarm_state_test` 用例 9 |
| **残余风险（重要）** | **QML 版的 `VitalSignSimulator` 从不产生 `artifact=true` 样本**（Widgets 版的 `injectArtifact()` 未移植），伪迹门控**只被单元测试覆盖，运行时无法演示**。这是「逻辑正确但无法触发」的验证缺口 |
| 残余 RPN | 4 / 2 / 3 = **24（需补运行时注入入口）** |

### H-4 数值被静默裁剪而掩盖病情（**已修复**）

| 项 | 内容 |
|----|------|
| 失效模式 | HR 250 被 `clamp()` 裁成量程上限 180 后显示 |
| 原因 | 数据路径误用 `ChannelConfig::clamp()` |
| 影响 | 危重程度被低估 → **严重伤害** |
| S / P / D | 4 / 3 / 3 → **RPN 36** |
| 控制措施 | 数据路径不做裁剪；超量程以 `↑` / `↓` 角标提示；`clamp()` 加 `@warning` 禁止用于告警路径 |
| 验证 | `alarm_state_test` 用例 8、9 |
| 残余风险 | 曲线可能被极端值压扁 → 需在绘图层做 Y 轴截断（**未实现，见 §4**） |
| 残余 RPN | 2 / 2 / 1 = **4（可接受）** |

### H-5 系统校时导致告警计时错乱（**已修复**）

| 项 | 内容 |
|----|------|
| 失效模式 | NTP 回拨 1 小时后，去抖 / 重复 / 升级计时全部失效 |
| 原因 | 计时使用 `QDateTime`（墙钟） |
| 影响 | 报警永不触发或疯狂重报 → **死亡** |
| S / P / D | 5 / 3 / 4 → **RPN 60** |
| 控制措施 | `monotonicMs`（`QElapsedTimer`）作为唯一计时基准；墙钟只用于显示 |
| 验证 | `alarm_state_test` 用例 10（模拟墙钟回拨 1 小时） |
| 残余 RPN | 5 / 1 / 1 = **5（可接受）** |

### H-6 报警被无限期静音 / 暂停（**已修复，QML 版新增**）

| 项 | 内容 |
|----|------|
| 失效模式 | 操作者静音或暂停后忘记恢复，报警长期无声 |
| 原因 | v1.1.1 之前 QML 版**完全没有声音、也没有静音 / 暂停能力**（只有横幅闪烁） |
| 影响 | **死亡** |
| S / P / D | 5 / 4 / 4 → **RPN 80** |
| 控制措施 | `AlarmNotifier`：暂停必须有时长（危急 ≤ 30 s、其余 ≤ 120 s）；倒计时每秒可见；**到期自动恢复**；恢复时若仍有未处理告警立即重新发声；静音只关声音、视觉提示保留；暂停 / 静音 / 恢复全部写审计与日志 |
| 验证 | `alarm_pause_test` 用例 2、3、5、7（上限收紧、到期恢复、提前恢复）、4、6、8（静音语义） |
| 残余风险 | 界面层（QML 按钮点击）无自动化测试，依赖目视验证 |
| 残余 RPN | 5 / 2 / 3 = **30（需可用性测试）** |

### H-7 暂停期间误以为「正在报警」（**已修复，QML 版新增**）

| 项 | 内容 |
|----|------|
| 失效模式 | 暂停后横幅若被隐藏或保持全彩闪烁，操作者会误判当前提示状态 |
| 原因 | 抑制状态不可见 |
| 影响 | 漏处置持续恶化的患者 → **死亡** |
| S / P / D | 5 / 3 / 3 → **RPN 45** |
| 控制措施 | 暂停时横幅**不隐藏**，改为中性灰 + 45° 斜纹 + 「恢复 N s」按钮；状态栏常驻徽标显示「报警已暂停 Ns」；暂停中强制停止闪烁动画 |
| 验证 | 目视验证（`qml/AlarmBanner.qml`、`qml/Main.qml` 状态栏） |
| 残余风险 | 无 GUI 自动化测试 |
| 残余 RPN | 5 / 2 / 3 = **30（需可用性测试）** |

### H-8 无音频输出时仍以为设备会报警（**已修复，QML 版新增**）

| 项 | 内容 |
|----|------|
| 失效模式 | 声卡 / 音频服务不可用，程序正常显示但永不出声 |
| 原因 | 引入 `QSoundEffect` 后新增的依赖（Widgets 版用 `QApplication::beep()`，不涉及） |
| 影响 | 医护认为「没有声音说明没有报警」→ **死亡** |
| S / P / D | 5 / 3 / 3 → **RPN 45** |
| 控制措施 | `AlarmNotifier::audioAvailable` 反映真实加载状态；报警时横幅显示「⚠ 无音频输出，仅视觉报警」，状态栏显示「N 级报警 · 无音频」；日志记录降级 |
| 验证 | `alarm_pause_test` 通过 `setAudioEnabled(false)` 验证策略层不受影响；界面提示为目视验证 |
| 残余风险 | 嘈杂 / 远距离环境下仅靠视觉提示的可靠性未验证 |
| 残余 RPN | 5 / 2 / 3 = **30（需可用性测试）** |

### H-9 历史文件损坏导致回放数据错误（**部分控制**）

| 项 | 内容 |
|----|------|
| 失效模式 | 文件被截断，解析时静默跳过坏行，回放出的曲线「看起来正常」 |
| 原因 | 旧实现忽略解析失败 |
| 影响 | 复查结论错误 → **中度伤害** |
| S / P / D | 3 / 4 / 4 → **RPN 48** |
| 控制措施 | `HistoryRecorder` 按行容错并上报坏行数；全部坏行则判失败 |
| 验证 | **无自动化测试**（QML 版未移植 `compliance_test`） |
| 残余风险 | 无 SHA-256 完整性校验、无 `LoadStats` 断言（`FileIntegrity` 未移植） |
| 残余 RPN | 3 / 3 / 3 = **27（需移植 FileIntegrity + compliance_test）** |

### H-10 越权修改报警限（**未控制，QML 版能力回退**）

| 项 | 内容 |
|----|------|
| 失效模式 | 非授权人员把 HR 高限改成 200 bpm，真实心动过速不报警 |
| 原因 | QML 版**未移植角色 / 权限体系**（`UserRole` 不存在），任何人都能改配置 |
| 影响 | **死亡** |
| S / P / D | 5 / 3 / 4 → **RPN 60** |
| 控制措施 | 仅保留可追溯性：配置变更逐字段写审计（旧值 → 新值）；患者类型切换写审计 |
| 验证 | 目视验证 + 审计日志检查 |
| 残余风险 | **无权限阻断** —— 必须显式记录为已知缺口 |
| 残余 RPN | 5 / 3 / 4 = **60（不可接受，需移植权限体系）** |

### H-11 采集线程卡死但界面显示「旧数据」（**未控制，QML 版**）

| 项 | 内容 |
|----|------|

| 原因 | **QML 版没有看门狗**（Widgets 版的 `heartbeat()` + `onWatchdogTick()` 未移植） |
| 影响 | 医护依据过期数据判断 → **死亡** |
| S / P / D | 5 / 3 / 5 → **RPN 75** |
| 控制措施 | 无 |
| 验证 | 无 |
| 残余风险 | 需实现心跳监控 + 数值过期灰显 |
| 残余 RPN | **75（不可接受）** |

### H-12 静音后忘记存在（**已控制**）

| 项 | 内容 |
|----|------|
| 失效模式 | 静音后横幅仍在闪，但没有声音，操作者离开后不再注意 |
| 影响 | 报警仅剩视觉，远距离可能漏看 → **严重伤害** |
| 控制措施 | 状态栏常驻徽标显示「N 级报警 · 已静音」；静音按钮变为深底「已静音」；静音状态写日志与审计 |
| 残余 RPN | 4 / 2 / 2 = **16（可接受）** |

| 项 | 内容 |
|----|------|

| 危害 | 初始 RPN | 残余 RPN | 状态 |

| H-2 传感器脱落 | 100 | 20 | ✅ 已控制 |
| H-3 运动伪迹 | 48 | 24 | ⚠️ 仅单测覆盖（运行时不可触发） |
| H-4 数值裁剪 | 36 | 4 | ✅ 已控制 |
| H-5 校时影响计时 | 60 | 5 | ✅ 已控制 |

| H-7 暂停状态不可见 | 45 | 30 | ⚠️ 已控制，需目视验证 |
| H-8 无音频输出 | 45 | 30 | ⚠️ 已提示降级，需可用性测试 |
| H-9 文件损坏 | 48 | 27 | ⚠️ 部分控制（缺完整性校验） |
| H-10 越权改限 | 60 | **60** | ❌ 未控制（无权限体系） |
| H-11 采集卡死 | 75 | **75** | ❌ 未控制（无看门狗） |
| H-12 静音被遗忘 | — | 16 | ✅ 已控制 |
| H-13 模拟数据误认 | — | 30 | ⚠️ 缺常驻演示标识 |

> **必须说清的一点**：H-10 与 H-11 在 Widgets 版里已被控制（权限体系、看门狗），
> 在 QML 版**尚未移植**。因此本表不是「QML 版比 Widgets 版更差」的结论，
> 而是「迁移范围外能力缺口」的清单。在补齐之前，QML 版只应被描述为
> **「报警链路完整、过程文件齐全」**，不应被描述为「合规」。

## 4. 尚未闭合的风险（下一步工作）

按残余 RPN 从高到低排序：

1. **H-11（75）**：移植 `VitalSignSimulator::heartbeat()` + 看门狗，
   并增加「数值过期」视觉状态（超过 N 个周期未更新则整屏灰显 + 遮罩）。
2. **H-10（60）**：移植 `UserRole` / `ensurePermission()`，改报警限需授权。
3. **H-13 / H-6 / H-7 / H-8（30）**：补常驻「演示模式」标识；
   开展 IEC 62366-1 可用性测试。
4. **H-9（27）**：移植 `FileIntegrity`（SHA-256 伴生清单）与 `compliance_test`。
5. **H-3（24）**：把 `injectArtifact()` 移植到 QML 版模拟器，使伪迹门控
   在运行时可见（目前只有单元测试能证明它工作）。
6. **H-4**：在绘图层做 Y 轴截断 + 溢出箭头，避免极端值压扁整条曲线。
